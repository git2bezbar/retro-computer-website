# Retro Computer Website

Everythin is based on https://edh.dev/ (formerly edwardh.io) and on Ed Hinrichsen's amazing work. I just adapted it to our needs.

---

This was a project was built in TypeScript and THREE.js, it contains a number of nifty features such as:
- 3D retro computer that you can interact with
- very simple UNIX shell implementation
- files system implementation
- markdown interpreter and renderer
- text layout engine

![Image of website](https://edh.dev/icon/og-img1.png)

## Build Instructions 
``` bash
# Install dependencies (only the first time)
npm install

# Run the local server at localhost:1234
npm run dev

# Build for production in the dist/ directory
npm run build
```
